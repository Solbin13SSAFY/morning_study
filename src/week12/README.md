## 📂 알고리즘 문제 정리  

### **📌 Tue**  
#### ⚖️ 백준 2629 - 양팔저울 ([문제 링크](https://www.acmicpc.net/problem/2629))  
- 주어진 추들을 양팔저울 양쪽에 배치해 특정 무게를 측정 가능한지 판단하는 문제.  
- DFS 방식으로 가능한 모든 조합을 탐색하며, DP 테이블에 방문 기록을 저장.  
- **부분합 개념과 메모이제이션**을 활용한 **상태 공간 탐색 + DP** 문제.

#### 📱 백준 7579 - 앱 ([문제 링크](https://www.acmicpc.net/problem/7579))  
- 메모리를 확보하기 위해 비활성화할 앱들을 골라 최소 비용을 구하는 문제.  
- DP로 앱의 메모리와 비용을 조합하여 **최소 비용으로 목표 메모리 확보**를 계산.  
- **0/1 Knapsack(배낭 문제)** 형태의 전형적인 **DP 테이블 구성 문제**.

#### 🐼 백준 1937 - 욕심쟁이 판다 ([문제 링크](https://www.acmicpc.net/problem/1937))  
- 대나무 밭에서 가장 오래 생존할 수 있는 경로를 탐색하는 문제.  
- DFS로 모든 칸을 순회하며 이동 가능한 경로를 찾고, DP로 최대 이동 거리를 저장.  
- **그래프 순회 + DP(메모이제이션)**의 결합으로 **탑다운 방식의 경로 최적화 문제**.

  - 특히 트리 DP는 완전히 생소했지만, 구조를 익히는 데 큰 도움이 되었고, **더 많이 접해봐야겠다는 동기**가 생김.

  - 특히 트리 구조와 함께 쓰이는 DP에서 **전략적 사고력 향상**에 도움이 되었음.  

### ✅ **이재빈**

## ✨ 스터디 총평  
이번 스터디는 **동적 계획법(DP)**에 대한 깊은 고민과 도전의 시간이었다.  
단순한 패턴 암기가 아닌, 다양한 자료구조(DP + 트리, DP + DFS 등)와 결합된 문제를 통해

무엇보다 익숙하지 않은 유형을 함께 탐구하며 스터디의 시너지를 느낄 수 있었다. 🌱
